I've written about how I'm trying to blog weekly this year, and how I'm going about working that kind of daily creative practice into my life. But the process has brought about more than just a lot of words, it's also forced me to reconsider how I'm using this space as a vehicle for sharing my work. Up until now, I've mostly blogs and then shared things on social media once or twice, and then on my work Slack channels, which is fine, but particularly since I'm just putting out so much content now I'm starting to think about how it can get lost in the fire hose of the content that I'm producing. And I want to think a little more about how to intentionally create spaces and ways for people to find their way into my material if they want. There are three ways I'm going to implement it to do this, and I thought I would share them with you here. The first is, I've implemented coins metadata on each post using this handy guy from Matthew Lincoln. So this metadata makes it so that if you're using something like Zotero, you can just easily pull things into your citation management software. It won't read it as a web page, but in fact, we'll get the actual metadata as appropriate and make it a little easier for you to cite it. Second, I have supplemented this with a suggested citation template. I actually drew this from the suggested citation snippet that we have on the scholarslab.org blog. Again, this is just another way to try and make the blog posts a little more salient as intellectual property, such that if you decide to use one of them, you don't have to think about how to do so and how to format it and making it a little easier for you. And lastly, this is perhaps what I'm most excited about I started trying to use button down to turn my RSS feed into an email subscription that you can sign up for to get notified about new posts from me directly to your inbox. So what this means is that every day, the button down checks my RSS feed, and if nothing is there, it doesn't do anything. Something is there that's new, it'll send an email to people who have subscribed. I've tested this in a soft way with some friends and family, so if it seems to work, but if you're one of the early people who signs up, I apologize for you. Know anything wrong with the feed, please do let me know. But I think this is a way to hopefully, if you know, if you actually want to keep up with what I'm doing, and you only occasionally see things come through my feed and you want to be sure you see them, or if you're you know a colleague or a friend who's not on social media and wants to be notified of me, writing this can be a way for you to keep up with it so you won't be spammed at most. I'm only going to be publishing once a week, but hopefully this will help to continue to turn this blog space into something a bit more substantial, and this was I was particularly excited about the button down RSS to email feature because I wanted to maintain ownership of my blog as a Jekyll site. I didn't want to have to rebuild everything, but I wanted to put it in such a space that I might actually be able to use it as a kind of a newsletter. So hopefully this will allow me to live that kind of hybrid double life that I'm looking for. So please do subscribe if you're interested. Share with other people who might be interested. You'll get lots more about teaching. pedagogy and education, digital humanities, video games, and whatever else that's going on with me this week.
